## 📺 OBS Studioでの導入・操作手順

本ツール（HTMLファイル）をOBS Studioに組み込んで表示・操作する手順です。

### 1. OBSにHTMLを追加する（表示手順）

1. OBSの **「ソース」** パネル下部にある **「＋」** をクリックし、**「ブラウザ」** を選択します。
2. 任意の名前（例：`カスタムオーバーレイ`）を入力して **「OK」** をクリックします。
3. プロパティ画面で **「ローカルファイル」** にチェックを入れます。
4. **「参照」** ボタンをクリックし、ダウンロードした `index.html` を選択します。
5. 必要に応じて **「幅」** と **「高さ」**（例：幅 `1920` / 高さ `1080`）を設定し、**「OK」** をクリックします。

> **💡 ヒント**
> HTMLやCSSを書き換えて変更が反映されない場合は、ブラウザソースのプロパティ下部にある **「現在のページのキャッシュを更新」** をクリックしてください。

---

### 2. OBS上でHTMLを操作する手順

OBSのプレビュー画面を直接クリックしても操作できないため、専用の操作ウィンドウを開きます。

1. ソース一覧から追加したブラウザソースを **右クリック** し、メニューから **「対話」** を選択します。
   （※ソースを選択した状態で、ツールバーの「対話」ボタンからも開けます）
2. 別ウィンドウで操作画面が開くので、通常のブラウザと同様にボタンのクリックや文字入力などを行ってください。操作内容は配信画面へリアルタイムに反映されます。
