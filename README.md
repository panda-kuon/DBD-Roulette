
1. HTMLファイルをOBSに表示する手順

1. ソースを追加する。 OBSの「ソース」欄にある「＋」ボタンをクリックし、「ブラウザ」を選択します。分かりやすい名前をつけて「OK」を押します。
2. ローカルファイルを指定する。 プロパティ画面が開いたら、「ローカルファイル」にチェックを入れます。
3. ファイルを選択する。 「ローカルファイル」の横にある「参照」をクリックし、PCに保存している対象のHTMLファイルを選択して「OK」を押します。
4. サイズを調整する。 必要に応じてプロパティ内の「幅」や「高さ」を変更し、配信画面に合うよう調整します。

. 表示したHTMLを操作する手順

OBSのプレビュー画面上で直接クリックしても、HTML内のボタンなどは反応しません。操作するには専用のウィンドウを開きます。
1. 追加したブラウザソースを右クリックし、メニューから「対話」を選択します。（ソースを選択した状態で、ツールバーの「対話」ボタンからも開けます）
2. 画面を操作する。 別ウィンドウでHTMLの画面が表示されるので、その中で通常のブラウザと同じようにクリック、スクロール、文字入力などの操作を行います。ここでの操作はOBSの配信画面にもリアルタイムで反映されます。
